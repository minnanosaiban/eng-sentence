英文学習

AI に作らせたオリジナルの英文です。同梱のサンプルとして、同期しなくても最初から表示されます。登録した英文には「AI作成」のグループが付きます。

自分で集めた英文です。公開はしません。同期（暗号化したクラウド同期）をしたときに表示されます。登録した英文には「収集」のグループが付きます。

英文を入れる

1行に1文で貼り付けます。解析(和訳・区切りなど)は、下の「Gemini API で解析する」か「他の AI のチャットで解析する」で付けます。

ファイルから入れるとき: .csv(1列目=英文、2列目=グループ名。「、」で複数)/ .txt(1行=1文)

すぐ試す(サンプル英文)

TOEIC風のオリジナル英文 154文(Part 1〜7。和訳・区切り・品詞・単語の発音記号・4択つき)を入れます。API は要りません。初めて開いたときは、自動で入ります。

AI に英文を作らせる: プロンプトをコピーして、チャットに貼る

API キーが無くても使えます。ChatGPT・Claude・Gemini などのチャットが英文を作り、そのまま解析した JSON を返します。返事は、下の「JSON を登録する」で登録します。

他の AI のチャットで解析する: プロンプトをコピーして、チャットに貼る

API キーが無くても使えます。英文を下に入れる(1行に1文)と、プロンプトに含まれます。空のままなら、チャットに英文を貼るひな形になります。チャットが返した JSON は、ファイル(.json)に保存するか、全文をコピーします。

AI に確認してもらう

登録した解析(和訳・区切り・品詞・4択など)に誤りがないか、他の AI のチャットで点検してもらいます。「選択」で英文を選んでから(10文まで)、プロンプトをコピーして、チャットに貼ります。返事の JSON は、下の「JSON を登録する」で「修正として取り込む」にチェックを入れて登録します。

JSON を登録する

チャットの返事(JSON)を貼り付けるか、保存した .json ファイルを選びます。アプリのバックアップ(.json)も、ここで読み込めます。

登録済みの英文を、5文ずつ解析する

すでに登録してある英文(解析が足りないもの)を、5文ずつ、チャットで解析します。プロンプトをコピーして、返事を貼り戻す、を繰り返します。

Gemini API で解析する

登録した英文に、Gemini API が、和訳・区切り・品詞・単語・TOEIC・4択を付けます(API キーが必要)。

設定(API キー・モデル)

API キーは、この端末のブラウザの中だけに保存します(バックアップ・同期には入りません)。呼び出しは、「解析する」を押したときだけです。1文ずつ、自動で呼びます。

発音記号を付ける

発音辞書(CMU Pronouncing Dictionary、アメリカ英語)から、発音記号が無い英文の区切りや単語に付けます。AI を使わず、API キーも要りません。語ごとの発音をつないだもので、辞書に無い語(数字・固有名詞など)を含む区切りには付きません。辞書(約0.8MB)は、必要なときに1回だけ読み込みます。
